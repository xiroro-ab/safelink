Cara Data ini Dihitung

Angka berasal dari data nyata, bukan placeholder. Satu kunjungan dihitung saat halaman safelink dibuka (GET /api/resolve). Setiap penyelesaian langkah verifikasi dicatat terpisah di server (POST /api/track), sehingga pengunjung yang melompat langsung ke langkah 3 tidak akan terhitung. Estimasi earning = kunjungan × 3 unit iklan × eCPM, dan hanya perkiraan kasar — pembayarannya tetap mengikuti laporan Adsterra.

Pengaturan Unit Iklan Adsterra

Disimpan di server dan langsung berlaku untuk semua pengunjung. Tidak ada lagi pengaturan iklan di halaman safelink.
